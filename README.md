# Telegram ИИ-нутрициолог + тренер — MVP

## Что уже есть

- Telegram-бот на aiogram
- согласие перед сохранением персонального профиля
- первичная анкета
- персональный ИИ-контекст
- питание
- тренировки
- свободные вопросы
- ежедневный отчёт
- недельный разбор
- простая память последних диалогов
- `/team` для администратора с агрегированной статистикой
- `/reset_profile` для повторного заполнения профиля

## Важно

Это MVP. Он не заменяет врача и не предназначен для диагностики.
Для реальной команды перед массовым запуском лучше:
- перенести SQLite в PostgreSQL;
- добавить резервное копирование;
- определить сроки хранения данных и удаление профиля;
- добавить отдельное согласие/политику конфиденциальности;
- не передавать руководителю персональные медицинские сведения;
- добавить мониторинг ошибок.

## 1. Создать Telegram-бота

1. Открой Telegram.
2. Найди `@BotFather`.
3. Отправь `/newbot`.
4. Укажи имя и username.
5. Получи токен.
6. Никому не публикуй токен.

## 2. Получить OpenAI API key

Создай API key в своей учётной записи OpenAI Platform.
Не публикуй его и не вставляй в переписки/репозиторий.

## 3. Настройка

Нужен Python 3.10+.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

macOS/Linux:

```bash
source .venv/bin/activate
```

Установка:

```bash
pip install -r requirements.txt
```

Скопируй `.env.example` в `.env` и вставь токены:

```env
TELEGRAM_BOT_TOKEN=...
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-5.6-luna
ADMIN_IDS=123456789
```

Чтобы узнать свой Telegram ID, можно использовать любого служебного бота для показа user ID или временно вывести `message.from_user.id` в логах.

## 4. Запуск

```bash
python main.py
```

После запуска открой своего бота и отправь:

```text
/start
```

   - 📊 Отчёт
   - 📅 Неделя
   - 💬 Спросить агента
   - 👤 Мой профиль

## Администратор

Добавь свой numeric Telegram ID в `ADMIN_IDS`.

Команда:

```text
/team
```

покажет:
- количество участников;
- сколько человек сдавали отчёт за неделю;
- общее число отчётов.

Персональные ограничения и вес в отчёт руководителя не выводятся.

## Быстрый безопасный запуск FitMyN
1. В @BotFather отзови старый токен и выпусти новый.
2. Новый токен не отправляй в чат.
3. Windows: запусти RUN_WINDOWS.bat.
4. macOS/Linux: chmod +x RUN_MAC_LINUX.sh && ./RUN_MAC_LINUX.sh
5. Установщик сам настроит описание и команды бота.
6. Для круглосуточной работы нужен сервер/worker-хостинг; Dockerfile и Procfile уже добавлены.
